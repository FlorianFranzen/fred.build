# Company logos

Each logo is a trademark of the respective company, shown nominatively in a list of
companies the studio has worked for. Every file was reduced to a single `currentColor`
fill with `design/clean-logo.py` and minified with `svgo`, so it follows the page's text
colour. Sources, fetched 2026-10-02:

| File | Company | Source |

| raiku.svg | Raiku | https://raiku.com/brand/raiku-intersect.svg (site brand folder) |
| web3-foundation.svg | Web3 Foundation | inline header SVG of https://web3.foundation |
| white-matter.svg | White Matter | https://white-matter.com/img/logo%20no%20text.*.svg (site header) |
| blackrock-neurotech.svg | Blackrock Neurotech | inline header SVG of https://blackrockneurotech.com |
| mpinb.svg | Max Planck Institute for Neurobiology of Behavior – caesar | https://www.mpinb.mpg.de/assets/images/logos/Logo_MPINB_en-v2.svg |

| parity.svg | Parity Technologies | https://www.parity.io/img/logos/parity_logo_dark.svg (site header) |
