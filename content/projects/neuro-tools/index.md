- **blackrock_file_info**: command-line tools to extract information from the `.nsx` and `.nev` files that Blackrock recording systems write, from the time the studio's founder worked on NeuroScope's Blackrock import.
- **homebrew-spikesorting**: a Homebrew tap with formulas for spike-sorting software, so a lab's macOS machines could install the toolchain with one command. Forked and used by others before the lab moved on.
