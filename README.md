# fred.build

Website of **F.R.E.D.** (Franzen Research, Engineering & Development), a prototype studio in
Zug. Static site built with [Zola](https://www.getzola.org), one stylesheet, and one small inline script
(the scroll highlight in the menu on the landing page; everything works without it).

## Develop

    nix develop          # zola, svgo, resvg, imagemagick, oxipng, fonttools, harfbuzz
    zola serve --drafts  # http://127.0.0.1:1111

or `nix run .#serve`.

## Build

    nix build            # ./result is the finished site
    nix flake check      # internal link check (zola check --skip-external-links)

## Content

- `content/_index.md`: the landing page text. The headline is in its `[extra]`.
- `content/blog/<slug>/index.md`: a post; images go next to `index.md` and are embedded with the
  `figure` shortcode. `hello-fred` is a draft, so the blog is empty in production until it is published.
- `content/projects/<slug>/index.md`: a project. `[extra]` keys: `repo`, `homepage`, `role`,
  `status` (`active`, `maintained`, `archived`; groups the list page), `period`, `tech`, `featured`
  (landing page), `cover_alt`. Each project has a generated `cover.svg` (see `design/README.md`).
  Pages with `draft = true` are kept for later and only appear with `zola serve --drafts`.
- `data/companies.toml`: the clients wall (`name`, `url`, `logo`, `size`, `label`). Logos are
  monochrome SVGs in `static/logos/`, sources in `static/logos/SOURCES.md`.
- `data/services.toml`: the services list and the grouped skill rows on the landing page.
- `data/contributions.toml`: upstream contribution figures and the projects shown under
  "Upstream contributions"; regenerate with `python3 design/contributions.py`.

## Design

Fonts, wordmark, favicon, cover plates and logos are generated by the scripts in `design/`; see
`design/README.md` for what each one does and for the one-off commands behind the raster assets.

## Deploy

Pushes to `main` build the flake in GitHub Actions and publish to GitHub Pages
(`.github/workflows/pages.yml`). `static/CNAME` pins the custom domain.
